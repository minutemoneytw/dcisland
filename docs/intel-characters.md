# 秘藥情報戰：角色卡規格

> 使用者在 2026-11-11 提供的角色卡設計（文字照原文，只調整標點），加上實作時補的名詞對照與判斷。
> 實作進度與程式細節見 `docs/notes.md`「和平島與遊戲桌」→ 秘藥情報戰 →「角色卡」；資料在 `client/assets/games/games.json` 的 `intel.characters`。
> 與規格有出入或不確定的地方，以使用者當下指示為準，並請更新這份文件。

## 總覽
- 每位玩家有一張**身分牌**（沙都／水都／咒術師）和一張**角色牌**。開局發 1 張身分、2 張角色，玩家選其中 1 張當本局角色，**另一張棄掉**。
- **咒術師身分不再靠集滿 3 張咒函獲勝，改用角色卡的「咒術勝利條件」**。沙都／水都仍是任一隊友情報區集滿 3 張自己顏色。
- 角色卡有兩種類型：**公開**（選完就翻開）、**隱藏**（選完仍覆蓋，只有本人與觀戰者看得到）。

## 通用規則（使用者定）
- **情報**：提到「情報」一律指情報區裡的情報。
- **親手殺掉**：自己使該玩家獲得最後一張咒函，包括該情報由你傳遞、將情報轉移給他、你使用的無人倖免、你的角色技能等。
- **類型**：「隱藏」的角色牌開局覆蓋，「公開」的開局翻開。
- **覆蓋規則**：角色卡覆蓋時，只能使用「翻開角色卡才觸發」的技能，其他技能都無法使用，但仍可宣告勝利。翻開後，所有技能恢復可用。
- **再覆蓋**：角色卡翻開後不能再覆蓋，除非自己用技能蓋回去（如篡奪者的妨礙），或被其他能覆蓋別人角色卡的技能蓋住。
- **識破**：角色卡的技能預設**不能被識破**，識破只能識破功能卡；如果角色技能是「把 XX 卡當成 OO 卡使用」且沒有註記不能被識破，那就是能被識破。

## 名詞對照（使用者 2026-11-11 說明）
| 詞 | 意思 |
|---|---|
| 鎖定 | 原本的「押送」改名，規則見遊戲內規則說明（只有輪到的人能用，指定一位玩家，本回情報到他手上就必須收下） |
| 查驗、竊取 | 新增的行動牌，規則見遊戲內規則說明 |
| 宣告勝利 | 結算勝利的瞬間 |
| 死亡／出局 | 同一件事；**文件與程式統一用「出局」**（收到第 3 張咒函） |
| 咒函 | 含黑色印記的情報（雙色黑也算）；**純黑**＝只有黑色一種印記 |
| 黃／藍情報 | 含黃／含藍印記的情報（雙色兩邊都算） |

## 實作判斷（助手補的，可以改）
- **咒術師也會出局**：角色卡模式下，咒術師收到第 3 張咒函也出局（因為他不再靠咒函獲勝，而規格裡有「成為第一個死亡的玩家」「你已死亡」等咒術勝利條件）。
- **只有咒術師身分用角色卡的勝利條件**：沙都／水都就算選了收藏家，也照原本規則（集滿 3 張自己顏色）獲勝。
- **咒術師各自計算勝利（使用者 2026-11-11 說明）**：咒術師不是同一陣營。①場上只剩咒術師**不算陣營獲勝**，遊戲繼續，直到有人達成自己的條件（或沒牌平手）；只剩 1 個人活著時沒人能傳情報，最後的倖存者獲勝（助手補的，避免卡死；沙都或水都只剩單一陣營時仍是該陣營獲勝）。②同一瞬間有多位咒術師達成各自條件（或與沙都／水都的勝利同時成立），就**一起獲勝**，除非像篡奪者那樣讓其他人落敗。這兩點在舊規則（角色卡關閉）也一併適用。
- **勝利條件何時檢查**：每次情報區／手牌／出局狀況改變後（收下情報、無人倖免、行動牌生效、回合開始抽牌後、有人離開）。
- **先結算勝利、再看場上陣營**：有人出局時，先檢查角色卡勝利條件（含絕望者「第一個死亡」，出局的人仍可獲勝），再檢查「場上只剩一個陣營」。
- **宣告勝利的結算**（`itDeclare`）：
  1. 篡奪者：場上**還沒有人出局**時，別人（包含沙都／水都）宣告的瞬間，活著的篡奪者（咒術師身分）奪走勝利，原宣告者落敗。
  2. 一起獲勝：局外人（活著、情報區 ≤1 張）、牆頭草（沙都或水都獲勝時，活著、情報區有 2 張以上咒函）、助人者（已出局、曾洗白獲勝者的咒函）。
  3. 「場上只剩一個陣營」的結束不算宣告，不套用篡奪者與一起獲勝。
- **親手殺掉的歸屬**：一般收下＝原傳遞者；轉移＝轉移者；鎖定逼他收下＝鎖定者；無人倖免＝使用者；自己害死自己不算。殺手要「第二位或以後出局」的人，狙擊手要出局當下「手牌最多（或之一）」。
- **選角**：限時模式 30 秒，逾時沒選的自動選第一張；不限時模式等所有人選完。選角中不能出牌。
- **角色卡開關**：桌主在開局前切換（預設關）。關閉時整個遊戲維持原本規則，咒術師集滿 3 張咒函獲勝。

| 1 | 謹慎者、雙面間諜、牆頭草、收藏家、情報商的技能（15 個）＋技能框架（主動技能、暫停選擇 `g.prompt`、識破時間內的反應） | **已完成（2026-11-11）** |

## 第 1 階段技能的實作判斷
- **自動觸發 vs「可」**：規格寫「可…」但幾乎一定有利的抽牌，一律自動：雙面（收下雙色情報抽 1）、兩邊倒（收下含咒函抽 1）、鑑識（截閱宣告成功額外抽 1）、囤貨（手牌 <5 張時抽牌階段抽 3 張）。需要玩家選擇的（保命、順水推舟、搜刮／偽造遺囑）才會暫停問人。
- **暫停（`g.prompt`）**：遊戲暫停，只有該玩家能回答（`tbl {a:'iprompt', ...}`，`no:true`＝不用）；限時模式 15 秒（`IT_HOLD_MS`）沒回答當作不用；不限時等玩家；暫停的人離開當作不用。答案不合法就維持暫停。
- **收下流程（`itRecv`）的順序**：保命（牆頭草，將收下第 3 張咒函）→ 放進情報區＋自動技能 → 順水推舟（情報商，收到咒函）→ 結算勝利／出局 → 搜刮／偽造遺囑（收藏家）→ 收尾（不限時確認或換下一位）。
- **搜刮／偽造遺囑**：有人因咒函出局，場上有（活著、已翻開的）收藏家時，死者的手牌先留著、記進 `g.lootQ`，等這次行動／收下結束後才問收藏家（所以勝利與場上陣營的結算在前）；收藏家一次可以搜刮 1 張（放手牌或自己情報區，放進情報區會再走一次勝利／出局檢查）並可同時偽造遺囑（一局一次，把死者情報區全部納為手牌）；死者剩下的手牌丟掉。
- **絕對謹慎**：在被鎖定／轉移選為對象的識破時間內使用（`g.pend` 根行動的 `tgt` 是自己），該行動標 `void`，生效時只記錄「被取消」，情報照一般流程處理。
- **偷天換日**：雙面間諜的雙色手牌可以用 `iact {as:'S', sel}` 當調包使用（走行動牌，可被識破）；**雙面人生**：`iskill {k:2, c}` 從牌堆找指定的雙色牌，牌堆重洗；`table.deckDouble` 只給本人看牌堆裡有哪些雙色牌。
- **避險／調節**：`iskill {k:1, hand:[a,b], intel}`：棄 2 張手牌、洗白自己情報區的一封咒函（避險隨時、調節只能自己回合投遞前）；洗白後會檢查角色卡勝利條件。
- **併購**：`iskill {k:2, tgt}` 先暫停讓他看對方全部手牌，再選拿 1 張、給 1 張。
- 技能預設不能被識破、不算行動牌（偷天換日例外）。技能需要角色卡已翻開（公開型選完就翻開）。
