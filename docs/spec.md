# DC島 — MVP 規格書 v1

> 概念：把「政策島」式的可愛 2D 點陣島嶼，放進 Discord 的語音頻道裡。
> **在同一個語音頻道 = 在同一座島上；沒在公共頻道時，就在自己的島上裝飾。**

---

## 1. 核心模型

| 概念 | 對應 | 說明 |
|---|---|---|
| 公共島 | Discord 語音頻道 | Activity 綁定頻道啟動，同頻道的人自動同島 |
| 個人島 | 每位成員 | 隨時可裝飾，他人可參觀（可設定鎖島） |
| 身分 | Discord 用戶 + 伺服器身分組 | 管理身分組可在公共島裝飾 |
| 資料 | 依 server id 隔離 | 跨群組互不相干 |

## 2. 遊戲層（2D 點陣風）

**視覺 UI 參考：FFXIV**（本群為 FF14 玩家群）。採用其 HUD 語言：
暗色半透明面板 + 細金邊 + 拉字距的小標題、裝飾模式仿 FFXIV 的家具編輯模式。

> 注意：僅風格參考。不使用 SE 之素材、圖示、字體或商標，避免版權問題。

- 渲染：Canvas 2D（MVP 自刻輕量引擎；必要時再升級 Phaser）
- 視角：固定一畫面一座島（島 ~24×13 格），版本 2 再考慮鏡頭跟隨
- 圖層：地面 → 平鋪物（地毯）→ 人物/家具依 Y 排序 → 名牌 → UI
- 操作：WASD／方向鍵走路；裝飾模式下點擊擺放／拿起家具
- 移動同步：MVP 本機單機；上線版 WebSocket 房間制（一座島=一個房間）

## 3. 內容全部走 manifest（加內容不改程式）

```
assets/
  terrain/<id>/terrain.json   地形調色、邊緣色、點綴物清單
  furniture/manifest.json     家具：名稱、尺寸(格)、是否可碰撞、sprite
  avatar/manifest.json        造型：膚色、髮型、上衣（調色換色）、配件
```

- 預設 6 地形：草島、沙灘、雪島、夜光島、森林島、熔岩島
- 第一批家具（demo 先 8 件）：沙發、桌子、椅子、植栽、地毯、電燈、電視、貓
- 新地形/新家具/新造型 = 加檔案

## 4. 造型系統

- 分層：膚色 → 髮型 → 上衣（調色換色）→ 配件
- 名牌：Discord 顯示名稱 + 身分組顏色（上線版）；頭像作為看板/名牌徽章
- 頭頂狀態：靜音/未靜音圖示（上線版由 voice state 提供）

## 5. Discord 整合（上線階段）

- Activity（Embedded App SDK）啟動於語音頻道 = 公共島
- 非頻道啟動 → 落點自己的個人島
- `*、workers.dev` 免費域名（Cloudflare 免費層部署：Workers + Durable Objects + D1）
- Bot：`/家具申請`、`/造型申請` → 審核頻道 → 一鍵上架；公告自動發到指定頻道
- 公共島裝飾限管理身分組（自景区分 UI）
