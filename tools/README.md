# img2pixel 工具（V1）

截圖／圖片 → 遊戲用像素素材（去背、限色、多幀動畫、sprite sheet／GIF／ZIP 匯出）。

## 使用

- **只需要 `img2pixel.bat` 這一個檔案**，雙擊即開（黑視窗會自動收起，工具在瀏覽器開啟）。
- 不需要安裝任何東西（Python 等都不用）；第一次執行會在桌面建立像素龍頭捷徑。
- 匯出的 ZIP／PNG 不會被 Windows 封鎖，存檔、解壓、開啟全部正常。
- 關掉工具分頁後，背景伺服器約 15 分鐘自動收工；工具內「專案」區也有「關閉伺服器」按鈕。
